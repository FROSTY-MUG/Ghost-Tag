Technical Specifications

Ghost-Tag v2.0.5 implements offline zero-knowledge encrypted NFC storage.

Canonical Envelope Structure

MAGIC (4B: "GHTG") FORMAT_VERSION (1B: 0x02) PURPOSE (1B: 0x01 Single | 0x02 Bulk) KEY_ID (16B CSPRNG) CIPHERTEXT_LENGTH (4B Little-Endian) IV / NONCE (12B CSPRNG) AUTH_TAG (16B AES-GCM) CIPHERTEXT (Encrypted Payload)

Cryptographic Primitives

  • AES-256-GCM: Authenticated symmetric encryption with 96-bit CSPRNG nonces.
  • PBKDF2-SHA256: 100,000 iterations over 32-byte salt for Key Encryption Key derivation.
  • 12-Word BIP-39: 128-bit entropy + 4-bit SHA256 checksum over English dictionary.
  • Cauchy Reed-Solomon: Erasure coding over Galois Field GF(2^8).

Security

Ghost-Tag executes exclusively in local browser memory. No passphrases, KEKs, DEKs, or decrypted files are ever stored on disk or transmitted over networks.

Privacy

Zero telemetry. Zero cookies. Zero external API calls. Offline-first local security utility.
