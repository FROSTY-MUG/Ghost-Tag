# Ghost-Tag Webhooks & Event Integration

Ghost-Tag defines event models and webhook payload architectures for notifying external monitoring systems, secure release pipelines, and alerting sinks (Discord, Slack, custom webhook listeners).

---

## 1. Webhook Security & Signature Verification

All outgoing webhooks generated by Ghost-Tag or GitHub Actions deliver an `X-Hub-Signature-256` header containing the HMAC-SHA256 digest of the request body calculated using a shared secret.

### Signature Verification Algorithm
```typescript
import * as crypto from 'crypto';

export function verifyWebhook(rawPayload: string, headerSignature: string, secret: string): boolean {
  const [algorithm, signature] = headerSignature.split('=');
  if (algorithm !== 'sha256' || !signature) return false;

  const expected = crypto.createHmac('sha256', secret).update(rawPayload).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(signature, 'utf8'), Buffer.from(expected, 'utf8'));
}
```

## 2. Event Types & Payload Schemas

### Event: `release.published`
Dispatched when an official signed release APK is deployed and verified.

```json
{
  "event": "release.published",
  "timestamp": "2026-11-15T18:00:00Z",
  "repository": "FROSTY-MUG/Ghost-Tag",
  "release": {
    "version": "v2.0.0",
    "apk_filename": "ghost-tag-v2.0.0.apk",
    "sha256": "f7218408023cd5e3eb3592074b1c7b07740c8751...",
    "download_url": "https://frosty-mug.github.io/Ghost-Tag/assets/ghost-tag-v2.0.0.apk",
    "environment": "production"
  }
}
```

### Event: `security.audit_alert`
Dispatched when an autonomous security audit or dependency invariant check detects an anomaly.

```json
{
  "event": "security.audit_alert",
  "timestamp": "2026-11-15T18:30:00Z",
  "repository": "FROSTY-MUG/Ghost-Tag",
  "severity": "CRITICAL",
  "rule": "AES_GCM_NONCE_REUSE_PROTECTION",
  "status": "FAIL_CLOSED_TRIGGERED"
}
```

## 3. Configuring Webhooks on GitHub

1. Navigate to **[Settings -> Webhooks](https://github.com/FROSTY-MUG/Ghost-Tag/settings/hooks)**.
2. Click **Add webhook**.
3. **Payload URL**: Enter your secure HTTPS endpoint.
4. **Content type**: `application/json`.
5. **Secret**: Enter a strong high-entropy secret token.
6. **Events**:
   - `Releases`: Triggered when release tags/APKs are published.
   - `Pull requests`: Triggered for security review automation.
   - `Security advisories`: Triggered for vulnerability notifications.
