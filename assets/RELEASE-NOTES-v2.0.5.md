# Ghost-Tag v2.0.5

Ghost-Tag v2.0.5 introduces a minimal, dark, premium cross-platform web client, standardized 12-word BIP-39 recovery phrases, single-tag arbitrary file storage, automatic NFC chip capability detection, and 72-hour encrypted local cache.

### Highlights
- **Minimal Brutalist Web Client**: Encrypted NFC storage directly in your browser over Web NFC / HTTPS.
- **12-Word BIP-39 Cross-Platform Recovery**: Unified mnemonic seed recovery interoperable with Android and web clients.
- **Single-Tag Arbitrary File Storage**: Store text, images, PDFs, ZIPs, or binary files on a single NFC tag when within capacity.
- **Automatic Chip Detection**: Real detected capacity reporting without manual chip selection.
- **72-Hour Encrypted Cache**: IndexedDB-backed encrypted chunk preservation with strict 72-hour TTL and auto-purge.
- **Verified Read-Back**: Guaranteed integrity verification comparing written tag payloads against source ciphertext before marking write complete.
