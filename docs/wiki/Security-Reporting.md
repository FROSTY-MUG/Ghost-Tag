# Security & Vulnerability Reporting

Do **not** open a public GitHub Issue for a security vulnerability or paste any secret, recovery phrase, passphrase, keystore, or key material.

## How to Report Privately
1. Navigate to the repository **Security** tab -> **Report a vulnerability**:  
   [https://github.com/FROSTY-MUG/Ghost-Tag/security/advisories/new](https://github.com/FROSTY-MUG/Ghost-Tag/security/advisories/new)
2. Include reproduction steps, impacted files/components, and severity assessment.

## Target Response SLAs (Best Effort)
- **Acknowledgement**: within **72 hours**
- **Triage & Severity**: within **7 calendar days**
- **Remediation / Mitigation Plan**: within **30 days** for high/critical issues

Full threat model, explicit security non-goals, and zero-secrets disclosure rules live in [`SECURITY.md`](../../SECURITY.md).
