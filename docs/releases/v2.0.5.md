Ghost-Tag v2.0.5 introduces a minimal, dark, client-side encrypted NFC storage web application deployed on GitHub Pages, featuring seamless interoperability with the Ghost-Tag Android client.

---

### Key Additions & Features

1. **Brutalist Web Client**:
   - Zero technical clutter on landing: `GHOST`, `Encrypted NFC storage.`, `[ Launch Web Version ]`, `[ Download Android APK ]`.
   - Apple-inspired brutalist dark styling with subtle blurred backdrop and smooth initial loading transition.
   - Deployed at: [https://frosty-mug.github.io/Ghost-Tag/](https://frosty-mug.github.io/Ghost-Tag/)

2. **Explicit Stop & Pause Controls**:
   - **Bulk Scan**: Visible `[Stop Scanning]` button that halts scan loop, preserves scanned tags in memory, calculates total usable storage, and provides `[Continue]`, `[Resume Scanning]`, and `[Cancel]`.
   - **Bulk Write**: Visible `[Stop Writing]` button that safely pauses in-flight chunk writing and verification, displays progress tally (`X / Y written, Z remain`), and provides `[Resume Writing]` and `[Cancel Session]`.
   - **Decrypt Scan**: Visible `[Stop Scanning]` button that halts scan and provides `[Decrypt Now]`, `[Resume Scanning]`, and `[Cancel]`.

3. **12-Word BIP-39 Cross-Platform Recovery**:
   - Deterministic 128-bit CSPRNG entropy with 4-bit SHA-256 checksum (132 bits total).
   - Interactive confirmation of 3 words before vault creation.
   - Full cross-platform recovery between Android APK and Web client.

4. **IndexedDB 72-Hour Ephemeral Cache**:
   - Automatic caching of scanned ciphertext chunks for up to 72 hours (`GhostVaultCacheDB_v2`).
   - Automatic cache expiration with live countdown timer and manual purge option.

5. **Mixed-Capacity Tag Optimization**:
   - Automatic capacity computation across mixed NTAG213, NTAG215, and NTAG216 tags.
   - Intelligent extra-tag exclusion instructing users when fewer tags are required than scanned.
