CORE CAPABILITIES

Designed with cryptographic rigor, zero cloud reliance, and deep Android hardware integration.

🔐

Two-Tier Key Hierarchy

Master Passphrase derives an ephemeral KEK via RFC 9106 Argon2id. Unique 256-bit DEKs are encrypted at rest with AES-256-GCM. Raw keys are never stored on disk.

🧩

Bulk Distributed Vault (v2)

Split arbitrary files (PDFs, videos, images, ZIPs) across physical NFC tags using Cauchy-Vandermonde Reed-Solomon erasure coding over GF(2^8) to tolerate lost tags.

🚫

Extra-Tag Exclusion Rule

Strictly prevents tag misuse. If a vault requires 86 tags out of 100 presented, Ghost-Tag prompts to set aside the 14 surplus tags and excludes them from writing.

⏱️

72-Hour Offline Cache

Scanned chunks are cached in encrypted offline storage with a strict 72-hour TTL and visual countdown, allowing asynchronous tag scanning across multiple days.

🛡️

Native C++ Security Core

Linux ptrace anti-debugging, /proc maps Frida/Xposed scanner, kernel page locking (mlock), and non-optimizable memory zeroization barriers.

🔒

Android Platform Hardening

FLAG_SECURE window protection blocks screenshots and task switcher previews. Hardware-backed Android KeyStore (TEE / StrongBox) secures master database keys.

LAYER 1: NATIVE C++ ENGINE

libghosttag_security.so

Compiled ARM64/x86_64 machine code executing ptrace(PTRACE_TRACEME) anti-debugging, parsing /proc/self/status TracerPid, and scanning /proc/self/maps for Frida agents (frida-agent.so, frida-gadget) and Xposed hooks.

LAYER 2: KERNEL MEMORY LOCKING

mlock() & Volatile Barriers

Locks key buffers into physical RAM via mlock() to forbid Linux kernel swap to flash storage. Multi-pass memory scrubbing (0xAA, 0x55, CSPRNG, 0x00) with asm volatile("" : : "r"(p) : "memory") defeats compiler dead-store elimination.

LAYER 3: ANDROID PLATFORM

FLAG_SECURE & KeyStore TEE

WindowManager.LayoutParams.FLAG_SECURE blocks screenshots, screen recording, and task switcher preview leaks. Hardware-backed AndroidKeyStore encapsulates master database keys in TEE / StrongBox.

LAYER 4: FAIL-CLOSED GATE

assertDeviceIntegrity()

If any integrity check fails (debugger attached, hooking framework active, root escalation detected), Ghost-Tag immediately executes panic zeroization of all active session keys and halts operations.
