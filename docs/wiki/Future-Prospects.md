# Future Prospects

Items listed here are **exploratory** and do **not** represent committed release dates or guaranteed features.

| Area | Prospect | Status |
|---|---|---|
| **iOS Write Support** | NDEF write capability on iOS CoreNFC beyond read-only beta (`PR #25` / [Issue #38](https://github.com/FROSTY-MUG/Ghost-Tag/issues/38)) | `Proposed` |
| **Desktop NFC Reader Expansion** | Additional PC/SC CCID readers beyond ACS ACR122U & ESP32/PN532 (`desktop/`) | `Under investigation` |
| **Additional NFC Chip Support** | Evaluation of higher-capacity ISO 14443-A / NTAG424 DNA tags beyond NTAG213/215/216 | `Under investigation` |
| **Cloud Recovery Improvements** | Custom SMTP email verification and Pro-tier automated backups / PITR when funded | `Proposed` |
| **Account Recovery Improvements** | Multi-guardian or split-knowledge recovery flows compatible with zero-knowledge guarantees | `Under investigation` |
| **Backup / Export Improvements** | Encrypted portable `.gtag` archive export/import independent of physical tags | `Proposed` |
| **Multi-Device Sync** | Encrypted metadata sync across Android, Desktop, and Web Companion | `Under investigation` |
| **Browser Extension / PWA** | Offline-capable PWA caching (`manifest.webmanifest`) and desktop bridge auto-discovery | `Proposed` |
| **Hardware-Security Improvements** | Android StrongBox / Keystore hardware-backed key wrapping | `Under investigation` |
| **Third-Party Security Audit** | Independent cryptographic review and penetration test prior to enterprise adoption | `Planned` |
| **Community Contributions** | UI accessibility, translations, reader drivers, and automated JVM/XCTest coverage ([Contributing](Contributing.md)) | `Planned` |
